# Architecture decision records

One short file per technical decision that would be expensive to reverse or that someone
will later ask "why did we do it this way?" about.

- Name: `NNNN-short-title.md`, numbered in order. Copy `_template.md`.
- Status: `proposed` → `accepted` (Eyup decides) → optionally `superseded by NNNN`.
- Never rewrite an accepted ADR. Write a new one that supersedes it.
- Link the spec(s) and the GitHub issue that triggered the decision. Label the issue
  `decision`.
